# ユーザーストーリー

- 種別: ユーザーストーリー

## ユーザータイプ

| タイプ | 説明                                                                                                                     |
| ------ | ------------------------------------------------------------------------------------------------------------------------ |
| 開発者 | アプリの所有者で、ただ 1 人の利用者。Mac Studio で動く Claude Code に複数のプロジェクトの作業を任せ、PC とスマホから使う |

## 用語

| 用語     | 意味                                                                                                                        |
| -------- | --------------------------------------------------------------------------------------------------------------------------- |
| 判断待ち | 利用者が判断しないと作業が進まない状態。設計の承認、AI の質問、許可の確認、merge 前の確認、失敗や利用枠切れによる停止を含む |
| 停止中 | issue の状態の 1 つ。AI の質問、失敗、利用枠切れ、CI の失敗、merge 前の確認、依存先の取り下げのどれかで進められず、利用者の判断を待って止まっている。一覧では判断待ちに出る |
| 指示待ち | 作業が一区切りし、次の指示を待っている状態 |
| 自分待ち | 判断待ちと指示待ちを合わせた呼び方 |

### Won't（今回はやらない）

| ストーリー                                        | やらない理由                                      |
| ------------------------------------------------- | ------------------------------------------------- |
| Codex など Claude Code 以外のエージェントを動かす | 初期版は Claude Code だけに絞る                   |
| 複数人で使う                                      | 自分専用のアプリとして作る                        |
| Claude Code の端末画面を表示する                  | スマホで読みにくく、アプリとキーを取り合う        |
| Neovim で選んだ範囲をエージェントへ送る           | 初期版の範囲に含めない                            |
| 別のマシンへ SSH で接続してエージェントを動かす   | Mac Studio の上で動くエージェントだけを対象にする |
| 利用者が画面の部品や配置を作り変える              | 初期版の範囲に含めない                            |
| アプリの issue を GitHub の issue へ書き戻す      | issue の管理をアプリに一本化する                  |
| 動いているエージェントとサブエージェントの出力を、専用の表示で見る | 作業中の会話とタイムラインで足りる |
| issue の状態・優先度・親・依存を 1 つの表示にまとめて見る | 使わない |
| 複数の箇所の引用を、1 件の質問・指示にまとめる | 引用 1 つごとに書いてストックする |
| ダークテーマ | ライトだけにする |
